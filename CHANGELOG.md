# Changelog

## 1.1.0

The bar reads the prefix `crafting:`. The craft plugin is named `crafting` from 4.12.0, because the Claude plugin directory keeps the name `craft` for a connector it already lists. With an older craft, whose commands start with `/craft:`, this version draws nothing: update craft, or stay on 1.0.0.

## 1.0.0

The craft bar moves out of the craft plugin into this one, because the Claude plugin directory accepts mods only from Verified organizations. Same bar, same store key; the command is now `/craft-bar:bar off` and `/craft-bar:bar on`.
